# Zermae Frontend

Next.js 16 App Router storefront plus a native Node HTTP API.

## Scripts

- `npm run dev` — Next.js on port 3000 and native API on port 5000
- `npm run typecheck`
- `npm run lint`
- `npm test`
- `npm run build`

Copy `.env.example` to `.env` and set `DATABASE_URL`, `HMAC_SIGNING_SECRET`, and `SESSION_SECRET` before running.
